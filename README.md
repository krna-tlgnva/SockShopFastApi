# SockShopFastApi

SockShopFastApi — это backend-проект интернет-магазина носков, разработанный на FastAPI.  
Проект реализует API для работы с товарами, корзиной, пользователями и заказами.

## Возможности

- REST API для интернет-магазина
- Каталог товаров
- Работа с корзиной
- Создание и обработка заказов
- Управление пользователями
- Быстрая документация API через Swagger UI
- Подходит для подключения frontend-приложения

## Технологии

- Python
- FastAPI
- Uvicorn
- SQLAlchemy
- SQLite / PostgreSQL
- Pydantic

## Для чего нужен проект

Проект демонстрирует создание backend-части e-commerce приложения на FastAPI. Его можно использовать как основу для интернет-магазина, учебного проекта или API-сервиса для frontend-приложения.
